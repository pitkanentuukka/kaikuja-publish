# kaikuja-publish

A personal command-line tool that publishes episodes and clips of the Finnish podcast
*Kaikuja Kaikkeudesta* to YouTube and other channels. It uses **YouTube API Services**
([YouTube Terms of Service](https://www.youtube.com/t/terms) ·
[Google Privacy Policy](https://policies.google.com/privacy)).
